rClone Sync

This is a personal desktop synchronization integration powered by the open-source rclone tool.

What it does

The integration uses Google OAuth authorization to connect the user's own Google Drive account with rclone on the user's own computer. It can list files and folders, upload and update files, and synchronize changes from selected local folders into Google Drive. Depending on the configured synchronization settings, this may include renaming or removing destination copies.

Why Google Drive access is needed

Google Drive permissions are used solely to carry out file synchronization requested and configured by the account owner. This website does not request sign-in, collect Google passwords, or store Google Drive files.

This application is for the owner's personal use and is not a public file synchronization service.
