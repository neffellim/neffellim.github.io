Privacy Policy — rCLONE Sync

Last updated: October 2026

Purpose and access

YOUR_APP_NAME is a personal desktop integration that uses the open-source rclone application to synchronize files from folders selected by the owner into the owner's Google Drive account. Google OAuth authorizes access to Google Drive. Within the permissions granted, rclone may list files and folders, read file metadata, upload or update files, and rename, move, or remove files where required by the user's synchronization configuration.

How Google user data is used

Google Drive data is used only to execute the file operations configured by the account owner. The integration does not operate an independent online file-hosting service or sell the owner's Google user data. Files synchronized into Google Drive are stored there under the owner's Google account and governed by Google's service terms.

Where data and credentials are stored

rclone operates locally on the owner's computer. OAuth credentials/tokens are stored in that computer's rclone configuration unless the owner chooses another storage location. Local logs may contain file paths, metadata, and error details. This public GitHub Pages website does not receive Google Drive files or OAuth tokens.

Sharing

The owner authorizes rclone to communicate with Google's APIs to maintain the requested synchronization. The operator of this personal integration does not intentionally disclose Google user data to other parties through this website or a separate application server.

Retention and deletion

File retention in Google Drive follows the owner's choices and Google Drive account settings. The owner can delete synchronized files from Drive, remove local rclone configuration files, or revoke this application's access in Google Account security settings.
